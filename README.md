# mcp-ieee
MCP server to give client the ability to search papers through IEEE Xplore


# Usage

```json
{
  "mcpServers": {
    "ieee": {
      "command": "uv",
      "args": [
        "--directory",
        "/home/algo/Documents/GitHub/mcp-ieee",
        "run",
        "python",
        "main.py"
      ]
    }
  }
}
```
